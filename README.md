# fusecode

Fuse config/code key checks for twelve-factor services.

**Site:** https://theworker02.github.io/fusecode/

## Install / run

```bash
git clone https://github.com/theworker02/fusecode.git
cd fusecode
node src/cli.js
node --test
```
